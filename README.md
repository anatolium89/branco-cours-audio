# BRANCO - Cours audio

Livraison des versions audio des cours BRANCO. Le lecteur principal et les cours écrits sont accessibles sur [droit.juan-branco.fr](https://droit.juan-branco.fr).

Le catalogue contient 87 cours et 696 chapitres. Chaque fichier conserve son empreinte SHA-256 ; les enregistrements restent chargés à la demande. La voix est celle de Juan Branco, produite avec ElevenLabs. Les fichiers déjà achevés ne sont pas régénérés.

[Accéder aux fichiers de la livraison](https://github.com/anatolium89/branco-cours-audio/releases/tag/2026-10-06).

Le fichier catalogue.json associe les chapitres aux cours et conserve leurs durées et empreintes. La disponibilité complète de la livraison est indiquée dans la note de livraison.
